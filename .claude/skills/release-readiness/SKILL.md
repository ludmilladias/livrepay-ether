# Release Readiness

Verifique produto, arquitetura, testes (`db:test`, `e2e.sh`), dados, IA, segurança, conformidade,
observabilidade, migração, rollback e documentação.

Retorne READY, CONDITIONALLY READY ou NOT READY. Não faça deploy.
