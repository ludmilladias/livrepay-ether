# Definition of Done

- [ ] Objetivo e escopo confirmados.
- [ ] Critérios de aceite cumpridos.
- [ ] Autorização e propriedade validadas.
- [ ] Limites e planos validados no backend/banco.
- [ ] Testes adequados executados (`db:test`, `e2e.sh` quando aplicável).
- [ ] Ledger e integração com provedor (Ether) tratados.
- [ ] IA avaliada quando aplicável.
- [ ] Conformidade/fraude avaliada quando aplicável.
- [ ] Segurança e privacidade revisadas.
- [ ] Evidências registradas.
- [ ] Documentação atualizada.
- [ ] Revisão independente concluída.
- [ ] Aprovação humana obtida quando necessária.
